# 洛水插件合集 · AstrBot Plugins

给 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 写的一批小插件，都是从日常使用里攒出来的：会话开关、用量统计、回复延时、引用概率、用户卡片、禁言、进群欢迎、壁纸工坊。

**这个仓库由洛水（AI 助手）和望山（GitHub：[@LuoShui319](https://github.com/LuoShui319)）共同制作。**
洛水负责写代码、改 bug、写文档；望山负责提需求、测试、挑毛病、定方向，以及把这堆东西打包发出去。
每一个插件都是在聊天里一句一句磨出来的，所以它们长这样、功能是这样，多多少少都带着两个人当时的需求。

## 安装

### 方法一：手动放进插件目录（推荐）

把 `plugins/` 下面想要的插件文件夹整个复制到 AstrBot 的插件目录：

```
AstrBot/data/plugins/
```

也就是复制完变成 `AstrBot/data/plugins/astrbot_plugin_xxx/`，然后重启 AstrBot 或者在面板里重载插件。

### 方法二：打包成 zip 上传

在 AstrBot 面板「插件市场 → 安装插件 → 从文件安装」里选择插件的 zip 包，zip 的第一层必须是插件文件夹本身（`astrbot_plugin_xxx/main.py` 这样）。

### 方法三：克隆整个仓库

```bash
git clone https://github.com/LuoShui319/astrbot-plugins-luoshui.git
```

然后把 `plugins/` 里需要的文件夹复制进 `data/plugins/`。仓库本身不放在插件目录里也没关系，插件是按文件夹识别的。

> 除「用户卡片」需要 `>=4.16`、「壁纸工坊」需要 `>=4.14.0` 以外，其余插件在 4.x 上都能用。

## 各插件说明

### 1. 会话开关 `astrbot_plugin_session_switch`

管理员指令，用来开关某个会话的 AI。关掉之后 AstrBot 不再为这个会话请求大模型，也就不会再回复、不会再烧 token。开和关都能定时，到点自动切换。

**权限**：AstrBot 全局配置 `admins_id` 里的管理员、插件白名单 `allowed_users`（默认 `3190568934`）、群主。普通成员发指令只会收到一句「没权限」。把 `admin_only` 关掉就谁都能用。

| 指令 | 作用 |
| --- | --- |
| `/会话 关` | 关掉当前会话，默认关到今天结束 |
| `/会话 关 2h` | 关 2 小时，支持 `30m`、`1d`、`今天`、`永久` |
| `/会话 关 到 8:00` | 关到早上八点，也认 `明天8点`、`8点半` |
| `/会话 开` | 打开当前会话 |
| `/会话 开 2h` | 现在打开，2 小时后自动关上 |
| `/会话 关 群 691314843` | 关掉指定群 |
| `/会话 关 私聊 3190568934` | 关掉指定私聊 |
| `/会话 关 default:GroupMessage:691314843` | 直接写完整会话号 |
| `/会话 状态` | 看当前会话开还是关，顺带看下次切换时间 |
| `/会话 列表` | 看所有挂着定时切换的会话 |
| `/会话 全开` | 一次性全部打开，并清掉记录 |
| `/会话 帮助` | 用法 |

别名：`session` / `会话开关` / `开关`。
时间写法：`2h`、`30m`、`1d`、`90`（纯数字按分钟）、`今天`、`永久`、`8:00` / `8点` / `8点半`（过了点自动算明天）。

**配置**：`admin_only`、`allowed_users`、`default_duration`（不写时长时默认关多久）、`check_interval`（到期检查间隔，秒）、`also_disable_tts`。

**原理**：关掉时写 AstrBot 自带的会话级 LLM 开关 `SessionServiceManager.set_llm_status_for_session(umo, False)`，面板里的会话状态会跟着变；同时在 `on_waiting_llm_request`、`on_llm_request`、`on_decorating_result` 三个钩子上兜底，关着的会话既不请求模型，也不会把已生成的内容发出去。定时记录存在 `data/plugin_data/astrbot_plugin_session_switch/sessions.json`，插件内部每 30 秒扫一次。

### 2. 会话用量统计 `astrbot_plugin_token_stats`

查某个会话的 token 消耗、缓存命中率和估算花费。

| 指令 | 作用 |
| --- | --- |
| `/token` | 本会话今天 |
| `/token 7d` | 本会话近 7 天 |
| `/token 30d` | 本会话近 30 天 |
| `/token all` | 本会话全部时间 |
| `/token 排行` | 今天所有会话的用量排行（带花费） |
| `/token 价目` | 看当前生效的模型单价表 |
| `/token 帮助` | 用法 |

别名：`用量` / `token用量` / `消耗` / `缓存命中`，后面接的参数一样。参数写错会直接回一句用法，不会静默。

**数据来源**：只读 AstrBot 主库 `data/data_v4.db` 的 `provider_stats` 表。

```
命中率 = token_input_cached / (token_input_cached + token_input_other)
花费   = 按 provider_model 分组，各段 token 乘单价再求和（元/百万 token）
```

**单价**：插件配置里的 `price_map` 填 JSON，例如 `{"deepseek-flash": {"input": 1, "cached": 0.2, "output": 4}}`，不填就用内置参考价。

**注意**：数据库以只读方式打开，不会影响 AstrBot 正常记录；语音、图片这类不产生 token 的往来不计入。`provider_stats` 里的时间戳存的是 UTC，算「今天」时会按配置的时区偏移换算。

### 3. 回复延时 `astrbot_plugin_reply_delay`

给机器人加一点「迟疑感」。每条要发出去的回复，先在配置的区间里随机抽一个秒数（默认 5~20 秒），抽到多少就等多少秒再发。一次回复里如果有好几条消息（框架的分段回复），每一条各抽各的。

**配置**：最小/最大延时、只对大模型回复生效、私聊/群聊生效范围、生效平台（默认 `aiocqhttp`）、输出延时日志。

**实现**：在 `on_decorating_result` 钩子里把当前事件对象的 `send` 方法换成带随机延时的包装函数。事件对象每条消息独享，所以不会串台；框架分段回复时是多次 `event.send`，天然做到一条一抽。

**不生效的场景**：流式输出；tool 里直接调用 `send_message_to_user` 发送的消息（绕过当前事件对象）。

### 4. 引用概率 `astrbot_plugin_quote_probability`

按概率给回复加上引用，替代 AstrBot 全局的「回复时引用原消息」。默认概率 0.1，也就是平均十条引用一条。

**前提**：先把 AstrBot 全局配置 `platform_settings → 回复时引用原消息` 关掉，否则框架会在插件钩子之后无条件再引用一次，概率控制会被覆盖。插件启动时检测到它还开着，会在日志里提醒一句。

**默认行为**：只在 `aiocqhttp`（OneBot / NapCat 等）生效；只对 LLM 回复生效；私聊和群聊都开；链上已经有引用、拿不到触发消息 id 时自动跳过；语音/图片打头的回复，引用会插到它们后面，避免 QQ 端显示错位。

**配置**：`quote_settings`（`enabled`、`probability`、`cooldown_seconds`、`only_llm_result`、`min_text_chars`）、`scope_settings`（`enable_private`、`enable_group`、`platforms`）、`debug_settings`（`debug_log`）。

### 5. 用户卡片 `astrbot_plugin_user_card`

通过 OneBot 接口拉取 QQ 用户资料（昵称、性别、年龄、QQ 等级、注册时间、群等级、入群时间等），结合本地补充库和可选第三方接口补齐生日、星座、生肖、现居、职业、VIP 等字段，用 Pillow 渲染成一张资料卡图片。

| 指令 | 作用 |
| --- | --- |
| `/用户卡片 @某人` | 查询被 @ 的人 |
| `/用户卡片`（回复某条消息） | 查询被回复的人 |
| `/用户卡片 12345678` | 直接发 QQ 号查询 |
| `/卡片设置` | 管理本地补充的资料 |
| `/卡片诊断` | 排查接口取不到字段的问题 |

**配置**：是否启用、新人进群是否自动发卡、资料缓存秒数（默认 600，避免频繁调用接口被风控）、第三方资料接口与密钥、是否允许查询他人、禁用群号、卡片样式相关。

**依赖**：Pillow；`fonts/` 里带了三个字体文件，不用额外装。

### 6. 禁言小工具 `astrbot_plugin_group_mute`

群内发「禁言 @某人 秒数」就能禁言，同时注册成 LLM 工具，让机器人可以在对话里主动调用。只有机器人是群管理时才会生效。

| 指令 | 作用 |
| --- | --- |
| `/禁言 @某人 60` | 禁言 60 秒，不写秒数默认 60 |
| `/解禁 @某人` | 解除禁言 |

秒数会被限制在 1 秒到 30 天之间；不能禁言机器人自己。给 LLM 用的工具名是 `mute_group_member`。

### 7. 进群欢迎 `astrbot_plugin_group_welcome`

新人通过审批或被拉进群时，自动发一条欢迎语，提醒先看群文件、群公告和群相册。不需要指令，装好即用。

**配置**：欢迎文案（支持 `{nickname}` 占位，会替换成新人的群名片或昵称）、总开关、生效群号（留空表示所有群）。

**排查**：欢迎没出来时先看日志里有没有 `[group_welcome]` 开头的行；确认当前平台适配器是 `aiocqhttp`，别的平台不一定发得出 notice。

### 8. 洛水壁纸工坊 `astrbot_plugin_wallpaper_luoshui`

把 AstrBot 面板（WebUI）的背景换成静态图或动态 mp4，所有参数都能在插件页面里调。换壁纸走交叉淡化，不会硬切。

**插件页面**：插件详情页点「壁纸工坊」进入管理界面，分四块：

1. **壁纸库**：顶部能按关键词搜壁纸（名字、文件名、来源路径），可切「全部 / 只看动态 / 只看静态」；每张卡片左下角有勾选框，支持全选、全不选、反选、批量加进轮换集、批量删除。单张卡片能预览、应用、改名、开关声音、删除；点「应用」后面板立刻跟着换，不用手动刷新。
2. **来源文件夹**：填 Wallpaper Engine 的 workshop 目录（例如 `D:\steam\steamapps\workshop\content\431960`）或任意图片/视频文件夹，点扫描就能看到识别结果。批量按钮都在结果列表**上面**那条常驻工具栏里：全选、全不选、只选动态、只选静态、导入时保留声音、导入选中，不用滚到最底下找，切「只看动态 / 只看静态」也不会丢勾选。
3. **上传**：本地上传静态图或 mp4，可选择是否保留声音；页面里会显示 ffmpeg 状态，没装可以点「自动安装 ffmpeg」。
4. **轮换集**：新建、改名、删除集合，把壁纸丢进集合，再选一个作为当前轮换集。

**外观参数**：字体颜色、遮罩透明度、模糊程度、页面底色、轮换模式、切换间隔、切换过渡时长（0~2500ms，0 表示直接切）、是否启用视频、视频质量等。既可以在插件配置页改，也可以在插件页面里改，改完点保存就会重新写入面板样式。另有「插件页面文字颜色 / 次要文字颜色」两项只管插件页面自己，次要色留空时自动按主色 72% 的透明度变淡。

**命令**：

| 指令 | 作用 |
| --- | --- |
| `/壁纸` | 查看当前壁纸状态 |
| `/壁纸 刷新` | 重新应用一次（改了配置没生效时用） |
| `/壁纸 下一张` | 换一张（按当前轮换集随机） |

**注意**：

1. 插件会读取并改写 `data/dist/index.html`，注入的代码块用 `<!-- astrbot-wallpaper:start -->` / `<!-- astrbot-wallpaper:end -->` 包裹，删除这两个标记之间的内容即可完全卸载。
2. 转码需要 ffmpeg。插件包里已经内置一份（插件目录的 `bin\ffmpeg.exe`），优先用它；没有就按 AstrBot 根目录 → 系统 PATH 的顺序找，全都没有会在后台自动下一份放进插件目录，也能在插件页面点「自动安装 ffmpeg」。
3. 面板样式是浏览器缓存的，改完记得 Ctrl+F5 强刷。

## 常见问题

**插件装上了但没反应？**
先重启 AstrBot 或在面板里重载插件；再看日志里有没有插件名开头的报错行。

**改了配置不生效？**
大多数插件是启动时读配置，改完重载一下；壁纸工坊改面板样式后记得 Ctrl+F5 强刷浏览器缓存。

**多个插件会打架吗？**
不会。会话开关、回复延时、引用概率用的都是不同的钩子，只是引用概率要求你把框架自带的「回复时引用原消息」关掉。
