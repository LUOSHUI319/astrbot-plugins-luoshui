# 进群欢迎

新人进群自动发一条欢迎语，提醒先看群文件、群公告和群相册。不需要指令，装好即用。

## 触发时机

有人通过入群审批，或者被别人拉进群时触发。

## 配置

| 配置项 | 说明 |
| --- | --- |
| 启用插件 | 总开关 |
| 欢迎文案 | 支持 `{nickname}` 占位，替换成新人的群名片或昵称 |
| 生效群号 | 留空表示所有群都欢迎，填了就只在这些群生效 |

## 排查

欢迎没出来时：

1. 先看日志里有没有 `[group_welcome]` 开头的行；
2. 确认当前平台适配器是 `aiocqhttp`（QQ 那条线），别的平台不一定发得出 notice。
