# 禁言小工具

群内发「禁言 @某人 秒数」即可禁言，同时注册成 LLM 工具，让机器人能在对话里主动调用。

只有机器人本身是群管理时才会生效。

## 指令

| 指令 | 作用 |
| --- | --- |
| `/禁言 @某人 60` | 禁言 60 秒；不写秒数默认 60 |
| `/解禁 @某人` | 解除禁言 |

## 说明

- 秒数会被限制在 1 秒到 30 天之间。
- 不能禁言机器人自己，会直接回一句「禁言失败：不能禁言我自己」。
- 只 @ 全体成员时不生效，认不出目标会提示重新 @ 一次。
- 注册的 LLM 工具名是 `mute_group_member`，参数 `user_id`（纯数字 QQ 号）和 `seconds`（默认 60），
  机器人可以在对话里自己判断要不要用。

## 平台

需要平台支持 `set_group_ban`，QQ 那条线（`aiocqhttp` / NapCat 等）没问题，别的平台可能不支持。
