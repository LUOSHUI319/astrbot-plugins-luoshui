# 会话开关

管理员指令，用开关某个会话的 AI。关掉之后 AstrBot 不再为这个会话请求大模型，
也就不会再回复、不会再烧 token。开和关都能定时，到点自动切换。

## 权限

只有这几种人能用：

1. AstrBot 全局配置 `admins_id` 里的管理员（`event.role == "admin"`）
2. 插件配置 `allowed_users` 白名单，默认 `["3190568934"]`
3. 群里的群主（`role == "owner"`）

普通成员发 `/会话 ...` 只会收到一句「这个要管理员才能用，普通成员碰不了」，
并且事件直接被掐掉，不会往下走。
把 `admin_only` 关掉就恢复成谁都能用。

## 指令

| 指令 | 作用 |
| --- | --- |
| `/会话 关` | 关掉当前会话，默认关到今天结束 |
| `/会话 关 2h` | 关 2 小时，支持 `30m`、`1d`、`今天`、`永久` |
| `/会话 关 到 8:00` | 关到早上八点，也认 `明天8点`、`8点半` |
| `/会话 开` | 打开当前会话 |
| `/会话 开 2h` | 现在打开，2 小时后自动关上 |
| `/会话 关 群 691314843` | 关掉指定群 |
| `/会话 关 私聊 3190568934` | 关掉指定私聊 |
| `/会话 关 default:GroupMessage:691314843` | 直接写完整会话号 |
| `/会话 状态` | 看当前会话是开还是关，顺带看下次切换时间 |
| `/会话 列表` | 看所有挂着定时切换的会话 |
| `/会话 全开` | 一次性全部打开，并清掉记录 |
| `/会话 帮助` | 用法 |

别名：`session` / `会话开关` / `开关`。

## 时间写法

- 时长：`2h`、`30m`、`1d`、`90`（纯数字默认按分钟）
- 到期点：`今天`、`永久`
- 钟点：`8:00`、`8点`、`8点半`、`20点30分`，过了点自动算明天
- 也可以加前缀：`到8:00`、`明天8点`、`at 9:00`

## 实现

- 关掉时调用 AstrBot 自带的 `SessionServiceManager.set_llm_status_for_session(umo, False)`，
  面板里的会话状态同步变化，AstrBot 主流程会在请求大模型前直接跳过。
- 兜底钩子：`on_waiting_llm_request`、`on_llm_request` 阻止插件自己发起的请求；
  `on_decorating_result` 清空结果，防止已经生成的内容发出去。
- 每次开关都会记一条「状态 + 切换时间」到
  `data/plugin_data/astrbot_plugin_session_switch/sessions.json`，
  插件内部每 30 秒扫一次：
  - 记的是关着 → 到点自动打开
  - 记的是开着 → 到点自动关上（关成永久，要手动再开）

## 配置

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `admin_only` | `true` | 只让管理员 / 白名单 / 群主用 |
| `allowed_users` | `["3190568934"]` | 额外允许使用的 QQ 号 |
| `default_duration` | `today` | 不写时长时默认关多久，可选 `today` / `forever` |
| `check_interval` | `30` | 到期检查间隔（秒），最小 5 |
| `also_disable_tts` | `false` | 关闭会话时是否一并关掉 TTS |
