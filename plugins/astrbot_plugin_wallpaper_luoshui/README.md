# 洛水壁纸工坊（astrbot_plugin_wallpaper_luoshui）

给 AstrBot 的面板（WebUI）换壁纸的插件。静态图、动态 mp4 都行，而且所有参数都能在插件页面里点着调。

| 能力 | 说明 |
| --- | --- |
| 扫描壁纸文件夹 | 填 Wallpaper Engine 的 `steamapps\workshop\content\431960` 目录或任意图片/视频文件夹，自动识别静态图与动态壁纸，并在插件页面里预览 |
| 本地上传 | 支持 jpg / png / webp / gif 与 mp4 / webm / mov，导入时可选是否保留声音 |
| 轮换壁纸集 | 新建多个集合，把壁纸丢进集合，切换当前轮换集，支持随机 / 顺序 / 固定一张 |
| 遮罩透明度 | 面板上那层白色遮罩的浓度，面板设置和插件页面都能改 |
| 界面字体颜色 | 可只改正文，也可强制覆盖全部文字（含按钮、标签） |
| 插件页面文字颜色 | 「壁纸工坊」插件页面自己的主文字 / 次要文字颜色，可选色或填十六进制，次要色留空就跟着主色变淡 |
| 模糊程度 | 0~40px，模糊时会自动放大一点避免边缘露白 |
| 切换过渡 | 换壁纸时双层交叉淡化，时长 0~2500ms 可调；静态图和动态壁纸都不会硬切、不会闪一下 |
| 其他 | 页面底色、去掉文字发光阴影、自动切换间隔、视频质量与宽度、一键关闭插件注入 |

## 安装

1. 把插件目录整个放进 AstrBot 的 `data/plugins/` 下（目录名保持 `astrbot_plugin_wallpaper_luoshui`）。
2. WebUI → 插件管理，点一次「重载」，插件列表里出现「洛水壁纸工坊」。
3. 打开插件详情页，切到「壁纸工坊」标签就是管理界面。

## 插件页面怎么用

页面分五个标签：

- **壁纸库**：卡片式预览，每张卡片能「应用 / 改名 / 加入集合 / 删除」，视频卡片点缩略图能直接试播。
- **来源文件夹**：一行一个路径，点「扫描」→ 结果里每个文件都有缩略图（点一下能放大看）→ 勾选 → 「导入选中」。视频会在后台转码成网页版 mp4，进度实时显示，转完自动跳回「壁纸库」预览。
- **上传壁纸**：选文件 → 勾「保留声音」（需要的话）→ 上传并导入。
- **轮换集**：新建/改名/删除集合，设当前轮换集，选轮换模式和自动切换间隔。
- **外观与播放**：字体颜色、插件页面主/次文字颜色、遮罩透明度、模糊、切换过渡时长、页面底色、视频开关与声音、转码质量，改完点「保存并应用」，面板会自己同步过来，不用手动刷新。
- **实时切换**：库里的「应用」按钮点下去，面板上会立刻换成那张，不用 Ctrl+F5（面板页里注入的脚本每两秒对一次数据，本地还有一条即时通道兜底）。

顶部「立即应用」会把当前轮换集重新写进面板样式；「刷新数据」重新拉一次状态。

## 配置项（插件设置页里也能改）

- `enabled`：总开关，关掉会移除注入代码块并清掉已发布的壁纸文件。
- `appearance.text_color` / `force_text_color` / `veil_opacity` / `blur` / `fade_ms`（过渡时长，0 = 直接切） / `background_color` / `text_shadow_off`
- `rotation.mode`（random / sequence / fixed）、`active_collection`、`fixed_item`、`switch_interval`（秒，0 表示只随刷新换）
- `playback.enable_video`、`video_sound`、`video_width`、`video_crf`、`keep_audio`
- `source.folders`、`auto_scan`、`recursive`
- `advanced.apply_on_start`、`watch_config`、`debug_log`

改完设置页保存后，插件会在 3 秒内自动重新应用（`watch_config` 打开时），不用手动点。

## 命令

| 命令 | 作用 |
| --- | --- |
| `/壁纸` | 看当前库、模式、遮罩、模糊 |
| `/壁纸 刷新` | 重新应用一次 |
| `/壁纸 下一张` | 随机挑一张并设成固定壁纸 |
| `/壁纸 开启` / `/壁纸 关闭` | 开关壁纸注入 |

## 文件都放哪

- 插件库与媒体：`data/plugin_data/astrbot_plugin_wallpaper_luoshui/`
  - `library.json`：壁纸元数据与集合
  - `media/videos/*.mp4`：转码后的动态壁纸
  - `media/stills/*.jpg`：静态图与视频抽帧
  - `media/uploads/`：上传的原始文件（导入后会自动删）
- 发布到面板：`data/dist/bg/astrwp_*.jpg` 与 `data/dist/bg/video/astrwp_*.mp4`（只保留当前轮换集用到的）
- 注入代码：`data/dist/index.html` 里
  `<!-- astrbot-wallpaper:start -->` … `<!-- astrbot-wallpaper:end -->` 之间

## 常见问题

**改了参数面板没变？**
遮罩、模糊、底色、字体色这类会自动同步；如果看到的是旧图，多半是面板页面还没重新加载过注入脚本（插件刚升级完重载一次插件、再 Ctrl+F5 一次就好）。

**换壁纸的时候会闪一下？**
正常的切换是「旧的淡出、新的淡入」，两层叠在一起过渡，不会出现纯底色的空档；如果看到明显一跳，先确认面板是重载插件 + Ctrl+F5 之后重新加载过（注入脚本要跟着更新），再把过渡时长调到 600~1200ms 之间试试。

**动态壁纸没声音？**
浏览器会拦截带声音的自动播放，需要点一下面板页面；右下角会出现一个「点击出声 / 点击静音」的小开关。另外导入时没保留音轨的话，之后是没声音的，得重新导一次并勾上保留声音。

**导入视频卡很久？**
4K 源转 1080p 大概十几秒一条，页面会显示正在处理哪个文件。嫌慢可以把转码宽度调小、CRF 调大。

**提示没找到 ffmpeg？**
把 `ffmpeg.exe` 放到 AstrBot 根目录（和 `astrbot` 文件夹同级）即可。

**过渡是怎么做的？**
注入结构里有 `#astr-wp-stack`（静态层容器）和 `#astr-wp-vstack`（视频层容器），每次切壁纸新建一层挂进去，新层淡入的同时旧层淡出，过渡结束后旧层才被移除，所以不存在「中间空一帧」。层级依旧是 静态(-4) < 视频(-3) < 遮罩(-2) < 面板(0+)。

**怎么完全卸载？**
禁用插件会移除注入代码块；彻底不要就删掉插件目录，然后手动删 `data/dist/bg/` 下 `astrwp_*` 文件。

## 目录结构

```
astrbot_plugin_wallpaper_luoshui/
├── main.py            插件入口：生命周期、配置监听、命令
├── wp_core.py         核心：库管理、扫描、ffmpeg 转码、注入块生成
├── wp_api.py          插件页面的 Web API
├── _conf_schema.json  插件配置项
├── metadata.yaml      插件元信息（含页面声明）
└── pages/manager/     插件页面（原生 JS，无构建依赖）
```
