# 洛水壁纸工坊 v1.0.8 更新说明

**发布日期**：2026-10-10
**适用版本**：AstrBot >= 4.14.0
**上一版本**：v1.0.7

---

## 一句话

这一版只干一件事：把「删了壁纸，它还在」这个老毛病彻底掐死。

---

## 修掉的问题

### 1. 点删除，壁纸还留在库里

三个坑叠在一起，之前一直没人发现：

- **文件被别的程序占着**。视频正在转码或正在被播放时，Windows 拒绝删除，旧代码把系统返回的报错直接吞掉了。
  结果是库里那条记录删了、`media` 里的文件还躺着，从外面看就是「什么都没发生」。
- **同一个源文件被导入过多次**。同一张壁纸反复导入，库里会留下几张长得一模一样的卡片。
  删掉其中一张，另一张还站在原地，缩略图完全相同，看起来还是没删。
- **浏览器拦了确认弹窗**。如果之前连点过几次删除并勾选了「阻止此页面显示更多对话框」，
  之后 `window.confirm` 会直接返回 false，删除按钮点下去等于没点，一声不响。

### 2. 删除失败不吭声

旧版无论成没成，前端都统一报一句「删掉了」。现在改成如实回报：删了就是删了，
被占着就说被占着，不再报喜不报忧。

---

## 新增与改动

| 改动 | 说明 |
| --- | --- |
| 删除失败自动重删 | 被占用的文件自动排队，隔 1.5 秒重试一轮，最多 8 轮；页面轮询状态时也会顺手再试一次 |
| 队列状态可见 | 还有几张卡在队列里，直接写在壁纸库工具栏的小字上，不再隐形 |
| 导入自动去重 | 同一个源文件只进库一次，从源头堵住重复 |
| 清理重复按钮 | 壁纸库工具栏新增「清理重复 (N)」，点一下每组只留最早那张，一次清干净 |
| 删除确认改版 | 不再依赖浏览器弹窗，改成按钮自己点两次确认，绕开弹窗拦截 |
| 删除结果如实回报 | 区分「已删除」和「被占用，排进队列」，不再统一报成功 |

## 升级方法

1. 面板「插件市场 → 从文件安装」选 v1.0.8 的 zip，或者直接替换插件目录
2. 在面板里重载插件
3. **Ctrl + F5 强刷页面**（面板样式有浏览器缓存，不刷会看到旧效果）

---

## 兼容性

- 配置项没有任何变化，旧的配置可以直接用
- 壁纸库 `library.json` 格式不变，旧库直接读，不需要重建
- 建议升级后进壁纸库看一眼工具栏有没有出现「清理重复」，有就点一下，把历史遗留的重复清掉

---

## 已知限制

- 被长期占用（播放器常驻、杀毒软件正在扫描）的文件，插件最多重试 8 轮。
  8 轮还没删掉会继续挂在队列里，重启 AstrBot 之后再点一次删除即可
- 重复判定按源文件路径为准。同一张图换了个文件名再导进来，不会被识别成重复
